= Example Transform
:plugin-id: EXAMPLE_TRANSFORM
:plugin-type: transform
:description: Demonstrates the documentation contract.

== Description

Reads rows and writes them unchanged.

== Input

One incoming row per file.

== Options

[cols="1,3,1"]
|===
|Option |Description |Default

|Field
|Field to read.
|

|===

== Output

One outgoing row per input row.

== Supported engines

[cols="2,1"]
|===
|Engine |Support

|Local
|Yes

|===

xref:../../examples/demo/example-transform.hpl[Example pipeline]

== Error handling

Fails on invalid input.

== Limitations

None.
